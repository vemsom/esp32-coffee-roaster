# Ongoing Notes

- 2026-10-03: rebuilt and re-flashed from a clean working tree at commit 72060ad so the device now reports build id "72060ad" without "+dirty"; this gives a verifiable firmware identity instead of an uncommitted merge tree.
- 2026-10-03: sensor-pinnarna omlagda för **det egna kretskortet** (eget beslut). Bara klockan delas (CLK 18); varje MAX6675-modul har nu egen SO och egen CS — SO-BT 19, SO-ET 21, CS-BT 4, CS-ET 17. CS-BT flyttad från GPIO5 (strapping-pinne, lämnas helt) till GPIO4 (samma kortsida som övriga sensorpinnar) och GPIO2 undviks (strapping + inbyggd lysdiod). Skälet till egna SO-linjer: en delad SO vilar på att den oselekterade modulens SO går i tre läge, vilket inte gick att bekräfta i databladet — på ett kort kostar den egna returlinjen ingenting. Se docs/wiring.md.
- 2026-10-03: CS-BT flyttad från GPIO13 till GPIO4 så att alla sensorkablar hamnar på samma sida av ESP32-kortet (samma sida som 16/17/18/19/21). GPIO4 är ledig, varken strapping-pinne eller ADC2-konflikt. Strömningsfrågan om GPIO5 är fortfarande borta. Se docs/wiring.md.
- 2026-10-03: ET reads about 6 °C high relative to BT at room temperature with both probes side by side. Added `SENSOR_OFFSET_ET_C -6.0f` applied after the fault checks in src/sensors.cpp; BT left at offset 0. Cause of the ET deviation not investigated; offset is only valid around room temperature and must be re-checked at roast temperatures.
- 2026-10-04: lowered `SENSOR_OFFSET_ET_C` to `-6.5f`. A live reading in room-temperature idle (2-min means from Home Assistant) showed ET ~24.7 C against BT ~24.2 C, i.e. ET still 0.5 C above BT, so ET was trimmed a further 0.5 C to line them up. BT unchanged. Still only verified around room temperature; the 2026-10-03 entry above is history, not the current value. Because the BT/ET cross-check compares calibrated values, the 0.5 C offset also moves the raw-figure trip point by 0.5 C (a raw pair must now differ by >21.5 C to beat `SENSOR_MAX_SPREAD_C`).
